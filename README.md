# pulseflux

Pulse and reshape flux text streams with deterministic transforms.

**Site:** https://theworker02.github.io/pulseflux/

## Install / run

```bash
git clone https://github.com/theworker02/pulseflux.git
cd pulseflux
node src/cli.js
node --test
```
